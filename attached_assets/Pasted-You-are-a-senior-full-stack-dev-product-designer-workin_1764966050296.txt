You are a senior full-stack dev + product designer working inside my Projournx trading journal app.

Your task:

Add a full “Prop Firm Mode” to the app, starting from the Dashboard UI + logic.

🎯 GOAL OF PROP FIRM MODE

When the user switches to Prop Firm Mode (PF Mode), the dashboard should behave like a prop firm challenge tracker:

User can set:

Account starting balance

Profit target % (default: 8%)

Max total drawdown % (e.g., 5% or 10%, plus custom option)

(Optional) Max daily drawdown % if easy

Dashboard then shows:

Progress toward Profit Target

Used vs remaining Max Drawdown

Visual alerts if they are close to breaching or have breached rules

🧩 IMPLEMENTATION REQUIREMENTS
1. Prop Firm Mode Toggle

Add a toggle switch on the dashboard:

Normal Mode / Prop Firm Mode

This toggle can be:

In the top right of the dashboard header, or

As a small segmented control: [ Live Trading ] [ Prop Firm ]

Default mode: Normal Mode (current behavior, unchanged).

When in Normal Mode → existing dashboard works as it does now.

When in Prop Firm Mode → use new prop firm calculations & UI described below.

2. Prop Firm Settings UI

Create a small settings panel (card) on the dashboard that appears in Prop Firm Mode:

Fields:

“Account Starting Balance” (number / currency)

“Profit Target %” (default 8%)

“Max Total Drawdown %” (dropdown: 5%, 10%, Custom)

If Custom is selected → show input for custom %.

(Optional) “Max Daily Drawdown %” input

Behavior:

Save these settings in the existing user/settings structure if possible.

Use sensible defaults if nothing is set yet.

3. Core Calculations (Prop Firm Mode)

Using user’s trades / PnL history and the prop firm settings, compute:

Current Equity = Starting Balance + Realized PnL (within this challenge)

Profit Target Value = Starting Balance × (Profit Target %)

Max Allowed Drawdown Value = Starting Balance × (Max DD %)

From these, compute:

Target Progress %

current_profit / profit_target_value * 100

Clamp at 0–100

Drawdown Used %

Based on max peak equity – current equity relative to max allowed DD.

dd_used = (peak_equity - current_equity) / max_dd_value * 100

Daily DD (if implemented):

Track equity PnL per day and compare with daily DD threshold.

Keep logic simple and robust.
If exact equity tracking is complex, make a best effort based on existing PnL structures without breaking anything.

In Prop Firm Mode, change the top part of the dashboard to:

Profit Target (in % and absolute value)

B. Progress Bars

Two main progress visualizations:

Profit Target Progress
